**S01 - State read from the log.** An invented site team (Cantiere Portoluna S.r.l., fictional) runs three clean cycles: a proposal acknowledged and decided, a proposal that receives a dissent, an answer and then the dissenter's consent, and a hand-off closed by a matching receipt. The check builds the repository and passes only if the tool, the independent reference reducer and the statuses declared by hand all agree (two proposals DECIDED, one dispute CLOSED, one hand-off RECEIVED, release gate OPEN, no violation), if `lint` exits 0, and if the answer of `status` names the commit it was read at. Run: `python scenarios/S01_state_from_log/check.py` - last line `S01_state_from_log PASS` or `S01_state_from_log FAIL`. Inputs: `input/` (git history as fast-import streams, written by `scenarios/make_inputs.py`). Expected: `expected/declared.json` (written by hand in `scenarios/stories.py`) and `expected/gold*.json` (reference reducer). Everything here is synthetic.
